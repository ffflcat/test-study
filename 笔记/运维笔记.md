### 思科设备的工作模式

```javascript
1.普通用户模式
Switch>
2.Switch>enable  #进入特权模式
Switch#
3.全局配置模式
Switch#configure terminal		#进去全局配置模式
Enter configuration commands, one per line.  End with CNTL/Z.
Switch(config)#
4.退出命令
exit
end（全局配置模式切换到特权模式）
```

#### 修改交换机名称

```
Switch>enable  					#进入特权模式
Switch#configure terminal		#进去全局配置模式
Switch(config)#hostname SW1		#修改交换机名称
#注：交换机命名根据公司要求，楼层-部门-作用
SW1#write						#保存
```

#### 接口

```
s口是serial接口，也叫高速异步串口，主要是链接广域网的v.35线缆用的，即路由器和路由器链接时用的，可以用命令设置带宽，一般10M，8M左右
F口是FastEthernet接口，也叫快速以太网口，主要链接以太网（局域网）用的，说白了就是链接交换机或电脑用的，用普通双绞线就可以链接，速率默认是100Mbps，可以用命令限速，但是不可能超过100Mbps
E口是Ethernet接口，叫以太网接口，也是主要链接以太网（局域网）用的，也是用普通双绞线就可以链接，速率默认10Mbps现在新型的设备上已经淘汰。另外，路由器上还有一个必不可少的接口是Console口，叫控制口，用来调试路由器。也有百兆千兆。
另外有的思科路由器还有AUX接口，也是控制口；
G口，是千兆以太网接口，是链接以太网用的

WAN口：广域网，国家链接
LAN口：局域网，某个公司，家庭，学校（范围小）
MAN口：城域网，城市之间
```

#### 配置console口密码

```
Switch>enable  					#进入特权模式
Switch#configure terminal		#进去全局配置模式
SW1(config)#line console 0		#进入console口
SW1(config-line)#password 1234	#设置密码
SW1(config-line)#login 			#登录

```

#### 配置进入特权模式密码

```
SW1(config)#enable password 1234	
SW1(config)#enable ?
  password  Assign the privileged level password	#明文
  secret    Assign the privileged level secret		#密文
SW1(config)#enable 
#备注：当明文和密文同时存在，以密文为主
#删除密码
SW1(config)#no enable password
SW1(config)#no enable secret
```
